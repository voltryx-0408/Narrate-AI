How Narrate-AI Works

14 AI-powered steps from a single topic to a finished documentary video.

PHASE 1 — RESEARCH & CONTEXT
1
NARRATIVE

Plan Outline

LLM analyzes topic, creates 3–5 section documentary structure

2
DISCOVER

Find Sources

Serper.dev Google Search finds authoritative websites

3
CRAWL

Extract Content

Crawl4ai extracts text, chunks into 500-word segments

4
INDEX

Vector Embed

MiniLM-L12-v2 embeddings stored in Pinecone for RAG

PHASE 2 — RAG & SCRIPT
5
QUERIES

Generate Queries

LLM creates semantic search queries for each section

6
RETRIEVE

Semantic Search

Pinecone similarity search retrieves relevant notes

7
SCRIPT

Write Narration

LLM writes documentary-style spoken narration script

PHASE 3 — VISUAL INTELLIGENCE
8
SEGMENT

Zone Detection

LLM finds visual breakpoints in script for image changes

9
PLACE

Image Mapping

Maps zones to segments, generates CLIP-ready descriptions

10
RETRIEVE

Search Images

Google Images via Serper, parallel downloads per segment

11
RANK

CLIP Ranking

OpenCLIP scores text–image similarity + quality metrics

PHASE 4 — PRODUCTION
12
NARRATE

TTS Synthesis

ElevenLabs or Edge TTS generates audio narration

13
TIMELINE

Sync Audio + Visuals

Calculates durations, syncs images to narration timing

14
RENDER

Ken Burns zoom, background music, ffmpeg mux → MP4
